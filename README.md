# Atannex Matrix

Handles reader engagement for any Laravel model: views, reading time, clicks, reactions, ratings, reviews, comments with replies, shares, bookmarks, follows and reports. It works for guests and signed-in users, keeps running totals and daily summaries, ranks what is trending, and gives moderators tools to deal with reported content. A JSON API lets the front end use it directly.

## Install

```bash
composer require atannex/matrix
```
